# MP Campaign (coordinator client + in-game server launcher)

Клиентская часть системы MP Sectors: карта секторов кампании, высадка на секторы и **запуск
сервера-координатора прямо из игры**.

## Установка

Скопировать `mp-campaign.jar` в `%APPDATA%\Mindustry\mods` (или `<папка игры>/mods`) и перезапустить
игру. Мод **видимый**: он должен стоять у всех игроков и на всех серверах (координатор и инстансы) —
версии должны совпадать.

## Запуск сервера из игры

1. Главное меню → кнопка **«Сервер кампании»** слева внизу (или `F9` в любой момент).
2. В окне:
   - **Папка сервера** — папка с `libs/server-release.jar`, `mods/mp-sectors.jar` и `campaign/`
     (по умолчанию `Desktop\MP-Sectors`, можно изменить);
   - **Серверный jar**, **Кампания**, **Java** — подставляются автоматически;
   - порты: игровой `6567`, HTTP `8090`, инстансы с `6570`;
   - лимиты: секторов `5`, игроков `10`, idle stop `60` с, память `1024` МБ;
   - галочка **«Разрешить 2 окна с одного ПК»** (по умолчанию включена) — сервер не блокирует
     одинаковые UUID/имена, можно зайти вторым окном для теста.
3. «Запустить» — мод копирует `mp-sectors.jar` и `mp-campaign.jar` в `coordinator/config/mods`,
   пишет `config/mp-coordinator.json` и запускает `java -jar server-release.jar`.
4. Статус под кнопками: запущен/остановлен, игроки, секторы, доступность HTTP.
5. «Карта» — сразу открыть карту секторов. «Остановить» — корректно сохранить и погасить.

Запуск идёт с JRE самой игры, отдельный JDK не нужен.

## Карта и высадка

1. Открыть карту: `N` или пауза → «Карта планет».
2. Слева сверху: игроки, секторы, домашний сектор; «Обновить», «Адрес», «В лобби».
3. Выбрать сектор → «Высадиться» (или двойной клик).
4. «Домашний» — сделать выбранный сектор домашним.
5. «Адрес» — HTTP-адрес координатора (при запуске из игры выставляется автоматически).

## Как работает

- `GET /sectors` — список секторов и `SectorInfo`; мод подставляет это в локальные `Sector`,
  поэтому ванильная карта рисует базы, атаки, названия и ресурсы.
- `POST /land` — координатор проверяет кампанию/лимиты, поднимает инстанс и возвращает `ip:port`;
  мод делает `ui.join.connect(host, port)`.
- `POST /home` — смена домашнего сектора.
- При выходе с сервера локальные данные кампании восстанавливаются.

## Сборка

```powershell
.\build.ps1     # нужен libs\Mindustry.jar (официальный клиент 160.6, не Steam)
```

## Ограничения

- UI проверялся сборкой и запуском серверной части из мода; сам экран в игре не тестировался.
- Сектор можно выбрать только если координатор разрешил.
- «Высадиться» на текущий сектор нельзя — вы уже там.
